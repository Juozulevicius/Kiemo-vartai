# Pakeitimai v0.3.0

Įgyvendinta kode:
- JSON atsarginės kopijos eksportas per Android CreateDocument langą.
- JSON atsarginės kopijos importas su formato patikra.
- Žemėlapio mygtukas atidaro išorinę žemėlapių programą, naudoja įvestas koordinates arba pavadinimą.
- Išlaikytas PIN/biometrijos vartas ir rankinio skambinimo srautas.
- Automatika aiškiai pažymėta kaip išjungta / neįdiegta.

Dar neįgyvendinta: integruotas Google Maps SDK, GPS geozonos ir automatinio skambinimo foninis variklis, tiesioginė Drive API sinchronizacija, skambučių istorija.

Patikra: ZIP turinys ir pakeisti failai sukurti, bet Android Gradle build ir įrenginio testas šiame etape neatlikti.
